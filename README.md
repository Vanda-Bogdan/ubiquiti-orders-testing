# Тестовое задание: обработка заказов

Скрипт на PHP 8.3+, который читает список заказов из JSON, валидирует их,
считает статистику по оплаченным заказам и сохраняет результат в `result.json`.

## Требования

- PHP 8.1 или выше (проверено на PHP 8.3)
- Composer
- Расширение `ext-json` (входит в стандартную сборку PHP)

## Установка

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ>
composer install
```

## Запуск

```bash
php code.php
```

Скрипт ожидает файл `data.json` в текущей директории. Результат записывается
в `result.json` рядом со скриптом.

### Пример `data.json`

```json
[
  { "id": 101, "customer": "Иван",  "amount": 1500, "status": "paid" },
  { "id": 102, "customer": "Мария", "amount": 2500, "status": "pending" },
  { "id": 103, "customer": "Пётр",  "amount": 3000, "status": "paid" },
  { "id": 104, "customer": "Анна",  "amount": 0,    "status": "paid" }
]
```

### Ожидаемый результат

Для исходных данных из задания `result.json` содержит:

```json
{
    "parsed_data": [ ... 4 заказа ... ],
    "paid_data": [ ... 3 оплаченных ... ],
    "total_amount": 4500,
    "paid_count": 3,
    "max_price_order": { "id": 103, "customer": "Пётр", "amount": 3000, "status": "paid" },
    "task_A": [ ... ],
    "task_B": { "paid": 3, "pending": 1 }
}
```

То есть:

- количество оплаченных заказов — **3**;
- общая сумма оплаченных — **4500**;
- самый дорогой оплаченный — **№ 103 на сумму 3000**.


## Обработка ошибок

Все исполняемые вызовы в `code.php` обёрнуты в `try/catch`. При любом исключении программа пишет сообщение в **stderr** и завершается с **exit code 1** — без стектрейса PHP.

Выбран режим **fail-fast**: при первой ошибке обработка прерывается, чтобы не выдать частичный результат как успешный.

| Ситуация | Поведение |
|---|---|
| Файл `data.json` не найден | `[ошибка] Файл не найден!`, exit 1 |
| JSON не декодируется | `[ошибка] Ошибка декодирования JSON: <причина>`, exit 1 |
| Некорректный заказ (нет поля, плохой `amount`, неизвестный `status`) | `[ошибка] <сообщение с ID>`, exit 1 |
| Оплаченных заказов нет | `max_price_order: null` в `result.json`, exit 0 |
